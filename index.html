🚀 Getting Started – Download & Setup

Follow these simple steps to get ai-manager running on your Windows computer in under 5 minutes. No coding skills needed!

  1. Visit the official download page: Visit this link to download the application
  2. Click the green "Code" button on the GitHub page, then select "Download ZIP".
  3. Find the downloaded ZIP file in your "Downloads" folder (usually named ai-manager-main.zip).
  4. Extract the ZIP file: Right-click on it and select "Extract All". Choose any folder you like, such as your Desktop or Documents.
  5. Open the extracted folder and locate the file named ai-manager.exe.
  6. Double-click ai-manager.exe to launch the application. That's it – you're done!

💡 Tip: You can right-click on ai-manager.exe and select "Pin to taskbar" to keep it handy. For easy access, you can also create a shortcut on your desktop.

Q: Do I need to install anything else first?

A: No. ai-manager is completely self-contained. Everything you need is included in the downloaded file.

Q: Windows says "Unknown publisher" – should I worry?

A: This is normal for open-source applications. Click "More info" and then "Run anyway" to proceed safely. ai-manager is open-source, meaning its code is publicly visible and verified by the community.

Q: How do I update ai-manager?

A: ai-manager checks for updates automatically when you open it. If an update is available, you'll see a simple prompt. Just click "Update" and the app does the rest.

Q: Can I use ai-manager on Mac or Linux?

A: Currently, ai-manager is built for Windows only. But the developers are working on versions for other platforms. Stay tuned!

Q: I accidentally deleted my settings. How do I restore them?

A: No problem. Just close the app, reopen it, and you'll be guided through the setup process again. Your AI tool connections are saved separately and won't be lost.

Q: The app won't start. What can I do?

A: Try right-clicking ai-manager.exe and selecting "Run as administrator". If that doesn't help, download the ZIP file again (it might have been corrupted during download) and try again.
